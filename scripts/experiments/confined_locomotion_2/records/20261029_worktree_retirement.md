## 两批已迁移采集优化

第一批批量缓存、故障检查和 Flat 到期行 raycast 的 512 环境有限对照：Flat 中位采集 9.31→6.93 s，Terrain 9.84→6.85 s。Flat 曾出现 11.60/12.75 s 慢样本，不能只挑选快样本承诺固定收益。第二批窗口/扫描元数据批量化相对上一批版本，Flat 6.492→5.928 s，Terrain 6.588→6.283 s；Terrain 波动明显，两批比例不可叠乘。

当时的时序检查在参考实现也触发 `2e-6` 阈值，首步误差约 `3.25e-6`。另行使用显式 `2e-5` 容差的 72 步诊断，最大时间特征误差约 `6.08e-6`、镜像历史约 `3.93e-6`；诊断不等于原门通过，未放宽正式检查默认值。采集编码分块 512 曾在 512 环境触发 Warp graph launch OOM，未采用，默认仍为 128。后续迁移回归另见迁移验收记录。

## 未采用方案及停止理由

| 试验 | 保留结论 |
|---|---|
| CPU 抽取完整噪声后仅搬运选中射线 | 扫描/特征和随机状态对照一致，但未提速；已撤回，不新增噪声 API 或随机流。 |
| 等长时间 GRU 跳过 pack/unpack | Terrain 128 环境，同 rollout、20 次 Adam；更新中位 4.394→4.470 s，最大网络/Adam 状态差约 `6.75e-6`，没有提速证据。 |
| PPO 固定整数索引替代布尔索引 | 同条件中位 4.340→4.363 s，状态差为 0，没有提速证据。两项小幅变化不解释为统计确定的退化。 |
| 直接包装 `make_graphed_callables` | 单调用对照通过，但未保留原激活重计算；两次不同输入前向再合并反向时梯度最大差 `0.00303026`，未通过 `atol=2e-5, rtol=2e-4`，不得接入训练。 |
| 自定义保留真实重计算的点 GRU 图原型 | 合成固定 packing 布局、单模块一阶参数梯度对照通过；计入构建成本后，128 条点序列 1.010→1.079 s，640 条 3.183→3.540 s，且 reserved 显存增加。没有满足速度条件，停止扩展，不接入训练。 |

图试验的 128/640 是一次 GRU 调用的点序列条数，不是环境数。后一个原型的多分支参数、Adam、末步梯度与输出最大差为 0，但没有验证完整 PPO、任意布局、输入梯度或高阶导数。640 条时普通/图原型 Torch reserved 约 1778/3172 MiB，其中图私有池约 1754 MiB；不能用很小的 Tensor allocated 数字宣称图路径低显存。

Terrain 128 环境一次设备 profile 中，实际 CUDA kernel 累计约 255.15 ms，cuDNN GRU 前向/反向合计约 94.6%。跨 stream 可重叠且不含主机空闲，该比例不是整轮墙钟占比；带 profiler 的耗时不能作为普通训练速度对照。
