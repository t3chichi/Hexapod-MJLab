# 快速开始：受限空间六足运动任务

> 只存放当前任务日常需要**直接复制执行**的终端命令。所有命令以仓库根目录为工作目录；更详细的训练边界和Checkpoint身份解释见[训练使用说明](../../../../docs/tasks/confined_locomotion/training/使用说明.md)。更新：2026-10-20。

## 1. 进入项目与运行环境

在新的 Ubuntu 终端中先执行一次，后续章节均以此为前提：

```bash
cd /home/t3chichi/Hexapod-MJLab
conda activate hp_mjlab
```

可选检查：

```bash
python --version

python -B scripts/experiments/confined_locomotion/train.py --help

```

## 2. Play：启动真实点云与地面网格可视化

下面的 `CKPT` 是**已经存在**的1次PPO更新GPU工程验证模型，适合检查点云/网格位置，但**不是收敛的行走策略**。实际评估训练结果时，将第一行改成新模型的完整文件路径。

```bash
CKPT="logs/verification/current/gpu_verification/task_baseline_integration_20261019/confined_locomotion_flat/2026-10-19_20-27-36_formal_56dfef9eeffb4273ba14569e6584e5c1/final_checkpoint_full_000001.pt"

python -B scripts/experiments/confined_locomotion/play.py \
  --checkpoint "$CKPT" \
  --output "logs/confined_locomotion/play_$(date +%Y%m%d_%H%M%S)" \
  --port 8093 \
  --export-exit-manifest
```

在**本机浏览器**打开 <http://127.0.0.1:8093>。默认**暂停**，可手动单步、继续、重置、修改速度，或启用“地面真值”图层。播放只加载网络权重，**不恢复训练状态，不更新参数**。

Play在不传`--grid-preset`或`--grid-x/--grid-y`时，自动读取**Checkpoint保存的真实监督网格**，不会误用后来修改的训练默认矩形。界面的**「候选地面监督范围（只显示，不修改策略）」**默认隐藏；开启后可调**最近端、最远端、左右半宽**三个数字，以蓝色候选框对比绿色真实监督边框，也可显示候选采样位置。候选数据仅供位置观察，**不改变模型预测、标签、网格身份或训练结果**；可随时“重置候选范围为Checkpoint原范围”。上述启动命令带`--export-exit-manifest`：关闭Play后，`--output`对应目录下的`manifests/manifest_*_exit.json`会记录`candidate_ground_rectangle`（三个候选数字与开关状态），便于以后将满意的范围手工同步到正式训练配置。

自动开始并给定初始前向速度（另起一次运行，仍使用上文的`CKPT`）：

```bash
python -B scripts/experiments/confined_locomotion/play.py \
  --checkpoint "$CKPT" \
  --output "logs/confined_locomotion/play_auto_$(date +%Y%m%d_%H%M%S)" \
  --vx 0.10 --vy 0.0 --wz 0.0 \
  --start-running --max-steps 500 --port 8093
```

`--max-steps 0`表示不限制运行步数；`--no-viewer`是无界面模式，必须同时带`--start-running`。每次Play的`--output`必须是**尚不存在**的新目录。可选扰动：`--preset clean|gap|gap_fixed0|range|proprio|all`（实际参数只选其中一项，默认`clean`）。

## 3. 从零开始正式训练

这不是已验收的长训推荐预算。请在提示后**亲自确定**种子、环境数和新增迭代数（RTX 4050 Laptop 6GB 注意显存）；不要把一次更新工程测试当作收敛训练。

```bash
read -r -p "训练种子（非负整数）: " TRAIN_SEED
read -r -p "环境数（正整数）: " TRAIN_ENVS
read -r -p "训练迭代数（正整数）: " TRAIN_ITERS

python -B scripts/experiments/confined_locomotion/train.py \
  --seed "$TRAIN_SEED" \
  --num-envs "$TRAIN_ENVS" \
  --max-iterations "$TRAIN_ITERS" \
  --gpu-id 0 \
  --log-root logs/confined_locomotion
```

默认使用当前**B8近端FPS256 + S1-187地面监督网格**，不需要另加网格参数。程序会创建独立的训练run目录，并在退出时输出 `run_dir` 与 `checkpoint_path`。**正式训练不要带`--engineering-validation`**。

## 4. 从完整Checkpoint断点续训

只有**当前完整训练Checkpoint**可以恢复optimizer、环境/传感器状态、随机流及计数器。必须与原训练的seed、环境数、源码、模型/场景、grid、依赖和设备等身份匹配；不满足时应拒绝，不能以Play的weights-only加载冒充续训。

```bash
read -r -p "完整Checkpoint文件路径: " RESUME_CKPT
read -r -p "原训练种子: " TRAIN_SEED
read -r -p "原训练环境数: " TRAIN_ENVS
read -r -p "本次新增迭代数: " EXTRA_ITERS

python -B scripts/experiments/confined_locomotion/train.py \
  --seed "$TRAIN_SEED" \
  --num-envs "$TRAIN_ENVS" \
  --max-iterations "$EXTRA_ITERS" \
  --resume-checkpoint "$RESUME_CKPT" \
  --gpu-id 0
```

`--max-iterations`在续训时代表**新增**iteration，不是训练后的累计总数。请从原训练run选择 `final_checkpoint_full_*.pt`，**不要使用**Play生成的场景文件、weights-only文件或随意更换网格；上方第2节的工程验证模型不作为正式长训续训的推荐起点。续训运行目录由程序根据完整Checkpoint路径解析，无须手工拼接`--log-root`。

## 6. 常用参数与地面监督范围

| 项目 | 哪里修改/如何指定 |
|---|---|
| 固定地面监督矩形 | `src/hexapod_mjlab/tasks/confined_locomotion/ground_presets.py` |
| 监督点数 | `S1_187_NX = 17`、`S1_187_NY = 11`，当前187点 |
| 默认网格 | 训练不带`--grid-*`使用当前S1-187；**Play不带网格参数直接使用Checkpoint保存的真实坐标** |
| 临时指定其他网格 | 同时传入完整`--grid-x`与`--grid-y`坐标序列；不能与`--grid-preset`混用 |
| 传感器分割及采样 | `src/hexapod_mjlab/tasks/confined_locomotion/scanner.py`（当前B8） |
| Play点选球大小 | `src/hexapod_mjlab/tasks/confined_locomotion/visualization/play.py` 的`PICKER_HIGHLIGHT_SPHERE_RADIUS_M` |

**修改四条边界即改变正式训练监督位置及网格身份**。即使仍是187维，新网格也不能直接配旧Checkpoint；当前镜像训练要求`y_min = -y_max`。**仅调整可视化范围，请使用Play里的候选矩形，不要修改上述源码边界。**

## 8. 常见错误速查

- **Play提示输出目录已存在**：换一个新`--output`；不要覆盖旧记录。
- **地址打不开/8093端口占用**：先检查Play进程是否正常启动，必要时用`--port 8094`，浏览器对应访问`127.0.0.1:8094`。
- **Checkpoint身份不匹配**：核对网格坐标、源码、环境数/种子/依赖；不建议用`--allow-source-change`掩盖不明错误（该参数也不能放宽完整续训身份）。
- **CUDA OOM**：不要直接提高环境数，先用较小的`--num-envs`做有界检查。
- **退出环境**：Play优先用界面“退出”；终端停止当前程序可尝试`Ctrl+C`；退出Conda使用`conda deactivate`。
