# 快速开始：Flat Baseline、Terrain Memory 与 Tripod2 Low

所有命令在仓库根目录执行。首次在新机器使用时，先按[部署说明](../../../../docs/tasks/confined_locomotion_2/training/部署.md)克隆 `main` 分支并安装环境。Flat Baseline、Terrain Memory和Tripod2 Low的配置、架构及信息边界见[任务说明](../../../../docs/tasks/confined_locomotion_2/README.md)与[Tripod2 Low](../../../../docs/tasks/confined_locomotion_2/tripod2_low.md)。

## 1. 准备运行参数

```bash
conda activate hp_mjlab

SELECTION=src/hexapod_mjlab/tasks/confined_locomotion_2/assets/fixed_channels/v1_hit10/near_x6_far_x10.npz
read -r -p "随机种子: " TRAIN_SEED
read -r -p "并行环境数: " TRAIN_ENVS
read -r -p "本次训练轮数: " TRAIN_ITERS
```

Flat v2、Terrain Memory和Tripod的新训练默认使用稀疏扫描、`hit_only_10m`及包内固定选集 `assets/fixed_channels/v1_hit10/near_x6_far_x10.npz`（near×6/far×10）。下方命令仍显式写出扫描参数，便于复现配方。`full`与`all_endpoints`仍可显式选择；续训PPO身份兼容的 `full/all_endpoints` checkpoint时，必须传回其原扫描参数，不能省略后静默改用新默认。

Flat v2、Terrain Memory和Tripod共用`TemporalPPOTrainer`与`TemporalPPOConfig`。新trainer schema为`temporal_ppo/v2`，Recipe必须记录`ppo_semantics`；直接优化初值1的std，KL用解析计算且不含旧epsilon，KL/熵只使用原始样本，每个rollout的一次shuffle顺序跨5个epoch复用。完整24步BPTT、镜像损失、Terrain高度辅助，以及每步pre-reset next_value的GAE语义均保留；termination不bootstrap，truncation bootstrap。旧checkpoint缺少新PPO身份时拒绝完整续训，不迁移Adam，也不视为与新训练等价；符合任务、架构和sampling条件时仍可按原sampling做weights-only Play。Tripod独立的Runtime/Runner、LSTM、奖励、动作和DR数值见[Tripod说明](../../../../docs/tasks/confined_locomotion_2/tripod2_low.md)。

## 2. 从零训练

按任务选择一个入口。环境数和轮数由本次训练预算决定；5090的容量与速度需在目标机测量。

### Flat Baseline

```bash
python -B scripts/experiments/confined_locomotion_2/train.py \
  --seed "$TRAIN_SEED" --num-envs "$TRAIN_ENVS" --iterations "$TRAIN_ITERS" \
  --gpu 0 --execution-mode low_memory \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION" \
  --log-root logs/confined_locomotion_2
```

```bash
python -B scripts/experiments/confined_locomotion_2/train.py \
  --seed 1 --num-envs 2048 --iterations 1000 \
  --gpu 0 --execution-mode low_memory \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection src/hexapod_mjlab/tasks/confined_locomotion_2/assets/fixed_channels/v1_hit10/near_x6_far_x10.npz \
  --log-root logs/confined_locomotion_2
```

### Terrain Memory

```bash
python -B scripts/experiments/confined_locomotion_2/train_terrain_memory.py \
  --seed "$TRAIN_SEED" --num-envs "$TRAIN_ENVS" --iterations "$TRAIN_ITERS" \
  --height-loss-weight 1.0 \
  --gpu 0 --execution-mode low_memory \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION" \
  --log-root logs/confined_locomotion_2
```

Terrain Memory 当前采用静态 Heightfield；11×17监督网格为X±0.75 m、Y±0.65 m。`1.0`是首轮高度损失权重候选，后续实验可显式调整。

### Tripod2 Low

```bash
python -B scripts/experiments/confined_locomotion_2/train_tripod2_low.py \
  --seed "$TRAIN_SEED" --num-envs "$TRAIN_ENVS" --iterations "$TRAIN_ITERS" \
  --gpu 0 --execution-mode low_memory \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION" \
  --log-root logs/confined_locomotion_2
```

Tripod独立保留Runtime、Runner和LSTM执行器；PPO与其它v2任务共用。训练配方、旧checkpoint兼容和weights-only Play详见[Tripod2 Low](../../../../docs/tasks/confined_locomotion_2/tripod2_low.md)。

三个入口均支持 `--execution-mode low_memory|speed`。默认 `low_memory` 在反向时重计算点GRU激活；`speed`保留激活以减少重复前向，需要更多显存。`--point-replay-chunk`接受正整数，默认1024，控制点GRU编码/重计算的分块大小；在RTX 4050可按工程需要设为256或128。该参数不改变24步BPTT、PPO minibatches或网络。它与Recipe/Checkpoint中的执行元数据一起记录，不作为完整恢复硬门。更多参数使用相应脚本的 `--help` 查询。

## 3. 保存与继续训练

训练目录位于 `logs/confined_locomotion_2/<实验名>/<run>/`，结束时终端输出完整checkpoint路径。默认每累计50轮保存 `checkpoint_full_XXXXXX.pt`，正常结束另存 `final_checkpoint_full_XXXXXX.pt`；用 `--save-interval` 修改间隔。保存和指标语义见[监控与保存](../../../../docs/tasks/confined_locomotion_2/training/监控与保存.md)。

续训使用原任务入口和原配方，追加 `--resume-checkpoint`；`--iterations`表示本次新增轮数。以下为Terrain Memory示例：

```bash
read -r -p "完整checkpoint路径: " CKPT
read -r -p "本次追加轮数: " EXTRA_ITERS

python -B scripts/experiments/confined_locomotion_2/train_terrain_memory.py \
  --resume-checkpoint "$CKPT" \
  --seed "$TRAIN_SEED" --num-envs "$TRAIN_ENVS" --iterations "$EXTRA_ITERS" \
  --height-loss-weight 1.0 --save-interval 50 \
  --gpu 0 --execution-mode low_memory \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION"
```

Flat续训改用 `train.py` 并去掉 `--height-loss-weight`；Tripod续训使用`train_tripod2_low.py`。必须保持原种子、环境数、采样配置和PPO/训练配方；Terrain还需保持原网格和高度损失权重。续训PPO身份兼容的 `full/all_endpoints` checkpoint时显式传入 `--raycast-mode full --far-sampling all_endpoints`，以及该checkpoint的其它扫描参数。源码、依赖、设备型号、执行模式、`--point-replay-chunk`和保存间隔不作为恢复硬条件，只作记录。上例适用于原权重1.0的模型，其他配方应替换成原值。

完整恢复要求匹配的 `hexapod_mjlab.model_physics/v1` 签名，以及Temporal PPO新身份`temporal_ppo/v2`和Recipe必需字段`ppo_semantics`，并检查名义模型和实际 Warp 静态物理值。缺少物理或PPO语义身份的历史文件拒绝完整续训；任务/架构/sampling符合条件时仍可用于下方weights-only Play。不会迁移Adam状态，也不把旧更新视作与新配方等价。新 Recipe/Checkpoint 记录启动时的 Git commit、dirty 和变更摘要，不以源码版本门控恢复。跨 GPU 完整恢复及5090容量仍待实测，详细政策见[监控与保存](../../../../docs/tasks/confined_locomotion_2/training/监控与保存.md)。

## 4. Play：原生 MuJoCo 控制

选择任务对应脚本和已有checkpoint；不同任务的checkpoint不能互用。以下以Terrain Memory为例：

```bash
read -r -p "要查看的checkpoint路径: " CKPT

python -B scripts/experiments/confined_locomotion_2/play_terrain_memory.py \
  --checkpoint "$CKPT" --seed "$TRAIN_SEED" --gpu 0 \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION" \
  --output "logs/confined_locomotion_2/play_terrain_$(date +%Y%m%d_%H%M%S)"
```

Flat使用 `play_flat.py` 并换成Flat checkpoint。Play默认打开原生 MuJoCo passive 窗口并暂停等待操作；按 Space 运行/暂停，F8 单步，Enter 重置，F12 退出。↑/↓ 调整前进指令，←/→ 调整侧移，Home/End 调整转向，Delete 清零指令；F9/F10 切换前一个/后一个环境。也可用 `--command VX VY WZ` 设置初始指令。Play 脚本不提供网页端口参数。

Tripod使用 `play_tripod2_low.py` 和Tripod checkpoint；配方说明及独立Runtime/Runner边界见[Tripod2 Low](../../../../docs/tasks/confined_locomotion_2/tripod2_low.md)。

无图形界面时可追加 `--no-viewer --steps 250` 进行有限推理；有限步数模式保留 `--steps` 参数。

需要网页检查时，使用独立的 `debug_terrain_memory.py`；Flat对应 `debug_flat.py`。Debug默认同时打开原生 MuJoCo 窗口和事件驱动的 Viser 网页，`--port`指定网页端口，`--no-native`可在远程只开网页，`--no-viewer`关闭所有界面。例如：

```bash
python -B scripts/experiments/confined_locomotion_2/debug_terrain_memory.py \
  --checkpoint "$CKPT" --seed "$TRAIN_SEED" --gpu 0 \
  --raycast-mode sparse --far-sampling hit_only_10m \
  --sparse-selection "$SELECTION" --port 8096 \
  --output "logs/confined_locomotion_2/debug_terrain_$(date +%Y%m%d_%H%M%S)"
```

网页运行时显示最近一次状态快照；暂停、单步、刷新、重置和指令预览会请求新快照。图层切换、点选与网格预览只重绘CPU快照，不推进物理仿真或GRU。扫描重建使用独立持久CPU展示模型，通过身份校验后复用展示窗口。可视化未做流畅度验收，不据此推断无卡顿。

Terrain界面可开关高度预测、真值、网格范围和六维包络；预测与真值使用相同高度参考，预测准确时应重合。候选网格只用于预览，不修改训练配置；实际训练网格从checkpoint读取。预测高度图和真值均不输入Actor/Critic。

Flat/Terrain的Play仍需显式指定与checkpoint匹配的扫描模式、sampling和选集；新训练默认值不改变Play的CLI默认值。`--allow-scan-override`仅用于同一sampling语义及固定catalog内的扫描配置评估，不用于严格续训，也不能跨任务或跨 `all_endpoints`/`hit_only_10m` 加载。

在远程训练机运行Debug网页时，可通过SSH端口转发访问，例如：

```bash
ssh -L 8096:127.0.0.1:8096 用户名@训练机
```
