# 文档分类与维护

## 分类

| 位置 | 内容 |
|---|---|
| `docs/README.md` | 导航、四个注册任务（含迁移对照）与八个入口 |
| `research/` | 跨任务架构、研究边界与机器人形态测量 |
| `tasks/confined_locomotion/` | 初版 Flat 任务入口、当前配置、接口、雷达与验收 |
| `tasks/confined_locomotion_2/` | Flat_2、Terrain Memory 与 Tripod2 Low 的入口、训练、部署与验收 |
| `development/` | 文档维护、记录保留与清理规则 |
| `development/history/` | 已结束的平台迁移历史；不作为当前实施指令 |
| `development/history/evidence/platform_migration/` | 平台迁移时期的五份历史数据，内容与运行身份保持原样 |
| `tasks/<任务>/baseline/evidence/` | 该任务历史交付基线的冻结证据 |
| `各主题 evidence/、figures/` | 冻结身份、实验配方及必要图表 |
| `logs/` | 运行时输出根（训练、Play、测试）；不承担长期历史证据管理；历史原始日志已删除 |

## 维护规则

- 每个主题保留一份当前权威说明。数值在配置文档维护，连接语义在架构文档维护，效果门在验收文档维护，其他文档引用它们。
- 当前目录、脚本、测试和正式入口使用功能名称。历史文档可以保留 `M0–M5`、`B8`、`S1`、`P0–P9` 等代号来描述当时的方案，但应在首次出现处说明其含义，不能把这些代号当作当前入口名称。
- 区分用户已确认、实现已验收、接口预留和仍待定；脚本存在或检查通过不能写成真实任务或学习完成。
- 移动或重命名文件时同步本地链接、代码引用、动态加载路径和生成脚本路径；不保留重复的旧目录入口，也不建立旧名兼容层。
- 不重写历史源码/模型/结果 SHA、验收阈值、失败分母或冻结配方。当前文件已变化时，以对应 run 的源码快照和身份记录复现。
- 删除文档前检查是否仍被当前权威文档、源码注释或检查脚本引用。历史运行路径可以保留为出处，但应明确标注为历史路径，不能当作当前文件链接。
- 整理完成后核查本地链接、章节锚点、代码块、冻结字节及代码变更范围；文档整理不作为算法或训练重新验收。

## 稳定出处路径

`MIGRATION.md` 继续作为平台迁移历史的简短入口，正文维护在 [平台迁移](history/平台迁移.md)。`tasks/confined_locomotion/development/实施计划.md` 保留为源码注释引用的历史出处索引，不作为当前计划。

当前任务入口、训练配方和验收结果分别以 `docs/README.md`、各任务 README、快速开始和 `training/` 下的当前说明为准。
