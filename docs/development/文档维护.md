# 文档分类与维护

## 分类

| 位置 | 内容 |
|---|---|
| docs/README.md | 导航与最短阅读路径 |
| research/ | 跨任务架构、总体规划、阶段成果和机器人测量 |
| tasks/<任务名>/ | 任务入口、当前配置、使用接口及验收；子目录按功能主题分类 |
| tasks/confined_locomotion/{README、平地配置、第一阶段说明} | 当前任务入口、数值配方与研究范围 |
| tasks/confined_locomotion/{framework、lidar_setup、mapping、reference} | 当前接口、传感、输出和设计依据主题权威页 |
| tasks/confined_locomotion/training/{功能状态、工程验收与复现、使用说明} | 当前状态、工程门和运行接口 |
| tasks/confined_locomotion/development/、history/ | 历史源码出处索引；独有结论进入当前说明，必要原报告见精简证据索引 |
| development/ | 共用工程规范与协作方式 |
| development/history/ | 已结束的平台迁移、维护记录，不作为当前实施指令 |
| 各主题evidence/、figures/ | 冻结身份、实验配方及必要图表 |
| logs/ | 必要原始数组、模型、失败、报告及源码身份；建设散件按保留清单归档或删除，不复制进当前说明 |

## 维护规则

- 每个主题只保留一份当前权威说明。数值在配置文档维护，连接语义在架构维护，效果门在验收维护，其他文档引用它们。
- 区分用户已确认、实现已验收、接口预留和仍待定；接口存在或脚本通过不能写成真实任务或学习完成。
- 已结束计划的独有内容合入实验记录或验收说明，删除重复计划。历史过程不进入默认阅读路径；冻结配方保留原字节，标明它不是新任务指令。
- 移动文件同步本地链接、代码注释和生成脚本的路径；文件名与代码包名不同须明确解释。不要保留重复的旧目录入口。
- 不重写历史源码/模型/结果SHA、验收阈值或失败分母。当前文件已变化时，通过该run的源码快照复现；文档整理前原件和路径映射须可追溯。
- 更新后核查本地链接、章节锚点、代码块、冻结字节及代码变更范围。文档整理不作为算法或训练重新验收。
- 建设结束后的保留与删除以[记录保留与清理](记录保留与清理.md)及逐文件清单为准。先核对依赖、关键最终证据与实质失败，再验证归档，最后删散件；被直接删除的非最终大数组明确不再承诺可恢复。
