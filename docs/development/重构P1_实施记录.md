## 复审补充修复（2026-10-28）

- **Tripod 执行器身份**：`actuator_sha256` 进入 v2/tripod 的 recipe 可选比较；新 tripod checkpoint 实际包含 `actuator_sha256=21e596...bdb135`，并记录 `env_semantics` 与 stage 0/1 `legacy_reward_scales`。旧文件缺少该字段时跳过，不因新增强制字段失效。
- **执行模式恢复**：`TemporalPPOTrainer.load_state_dict()` 不再要求 saved `execution_mode` 与当前一致；只校验取值属于 `low_memory|speed`。当前 trainer 保留本次请求的模式。Flat/Terrain 共用该 trainer；Tripod `LegacyPPOTrainer` 继承同一加载路径。新增 v2 与 tripod CPU 测试。
- **训练语义白名单**：v1 新增可选 `action` 块（raw_clip/residual_scale/stiffness/damping/effort_limit），旧文件缺失时跳过；v2/tripod 新增可选 `env_semantics`（action、reward weights、termination names/time_out + 公共阈值、sim timestep/decimation/step_dt）及 tripod `legacy_reward_scales`。旧 v2 1000 轮 checkpoint 缺少这些可选字段，identity 比较仍通过。
- **JSON 兼容**：Tripod LSTM 执行器的 `effort_limit=inf` 在 `env_semantics` 中编码为字符串 `"inf"`，避免 `allow_nan=False` 写 recipe 失败，不改变实际执行语义。
