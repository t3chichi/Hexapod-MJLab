# 记录保留与清理

更新：2026-10-27。

## 当前原则

`logs/` 只作为正式任务和测试的运行时输出根目录：

- `logs/confined_locomotion/`
- `logs/confined_locomotion_2/`
- `logs/verification/`

历史工程训练、checkpoint、rollout 状态、重复验证记录和旧任务日志已在 2026-10-27 清理。删除后不承诺恢复，也不在 `logs/` 中长期保存历史报告或研究证据。

## 持久研究资料

需要长期保留的结论、配置摘要、冻结身份与研究输入放在 Git 跟踪的 `docs/` 和 `tests/data/` 中，例如：

- `docs/research/morphology/evidence/library.json`
- `docs/research/morphology/evidence/release.json`
- `docs/research/morphology/evidence/hold_results.json`
- `docs/research/morphology/形态可达性测量.md`
- `docs/research/morphology/实验记录.md`
- `docs/tasks/<任务>/baseline/evidence/` 与当前任务说明

历史文档中的 `logs/` 路径只表示当时出处，不再保证文件存在；不得把被删除的原始数组、checkpoint 或完整运行目录描述为仍可恢复。

## 后续清理

清理前核对实际读取依赖、必要输入与当前研究结论。只删除已授权内容；未知用途先查证。若决定放弃原始数据，明确写出恢复/逐帧复验能力已经撤销；当前摘要和验收结论不能替代未来论文研究所需的原始测量数据。
