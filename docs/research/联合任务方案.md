更新：2026-10-12（同步当前工程验收与目录入口，研究顺序不变）。论文目标是六足机器人结合感知、预测形态与运动指令，学习复杂受限空间中的全身协同通行。现有二维oracle、测量和管线成果为研究基础；完整联合任务尚未实现。

当前命名、状态与实施批次由[任务入口](../tasks/confined_locomotion/README.md)维护；连接见[架构](训练架构对齐.md)，首版数值及后置事项见[启动配置](../tasks/confined_locomotion/平地学习与基准测量.md)，交付与效果门见[第一阶段说明](../tasks/confined_locomotion/第一阶段任务说明.md)。

## 受限场景的准备要求

- 环境碰撞、雷达与真值使用一致场景几何；机器人完整碰撞体参与物理，但首版雷达仍只扫描环境，不由同源要求自动加入自遮挡；低顶同一水平位置同时存在地面和顶棚，单值高度场不足。
- 核查地面、侧壁及顶棚命中/采样、水平teacher的近端观测支持，量化未补偿历史的运动误差；适配EA2旧ego右向为正的坐标。
- teacher联合满足水平/高度与机器人约束，复核完整占据及转换；分开记录有效、当前位姿无参考、求解失败/超时和有证据的场景不可通。
- 旧固定体高、默认腿位和镜像正则须审查是否妨碍必要变形；接触计数遵循启动配置，奖励保留项与权重另定。

具体尺寸、划分、teacher代价/安全间隙/预算、失败处理及效果门在受限实施前确认。现有二维oracle参数不自动迁入。

## 基线之后的候选方向

| 基线问题 | 候选优化 |
|---|---|
| 形态辅助与控制持续冲突 | 从可信checkpoint开放包络回传；强度与调度按训练证据讨论 |
| 覆盖不足、历史混叠或遮挡 | 覆盖/窗口调整、运动补偿、跨控制步记忆或顶棚辅助表征 |
| 参考无效率高或转换不及 | 改进耦合可达域、转换/扫掠复核及参考稳定性 |
| 固定/对称形态限制策略 | 非对称表达、相位先验或按速度/方向条件化基准 |
| 未见场景或扰动泛化不足 | 域随机化、课程、组合场景及更复杂地形 |
| 极端动作或绊碰判据与失败相关 | 复核±100裁剪及旧净力比，再决定是否改动 |
| 非平面或实机阶段 | 地面参考、速度估计、延迟/接触建模及机械/执行器标定 |

这些是按证据选择的方向，不是已批准的实验队列。特权critic不是当前重点；核心对照类型、数量及预算待定，无对照只报告基线表现，不宣称因果优势。
