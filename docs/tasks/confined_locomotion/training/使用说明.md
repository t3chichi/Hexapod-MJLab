# 正式任务训练与任务 Play 使用说明

更新：2026-10-19。本页仅说明当前生产API/CLI和身份要求。历史日志说明：文中 `logs/` 路径为当时工程验收出处；原始日志已在 2026-10-27 清理中删除，当前复现需重新运行检查。当前源重构的CPU/GPU工程门见[功能状态](功能状态.md)与[工程验收与复现](工程验收与复现.md)。B8近端与S1-187相对高度网格已确定为正式任务首版配置；正式训练预算、种子、地形可观测性与学习效果仍需在对应阶段验收；本文不提供长训默认值。

## 网格配置

正式任务注册配置与任务专用训练、Play入口默认共用S1-187的完整`GroundGridCfg`，仍允许显式替换网格以进行历史对照；Python正式/工程factory的`ground_grid`形参继续要求完整对象，不隐式猜测自定义坐标。`validity_mode`仍是`geometry_only_flat_training`。序列坐标递增，顺序以y为外层、x为内层，M由坐标数相乘派生。`parallel_tol`默认`1e-6`并进入identity，不能在不同运行间省略身份比较。Python调用时的核心形式为：

```python
from hexapod_mjlab.tasks.confined_locomotion.ground import GroundGridCfg

grid = GroundGridCfg(
    x_coords=(...),
    y_coords=(...),
    validity_mode="geometry_only_flat_training",
)
```

2026-10-19用户确认并已同步到正式任务默认配置的固定相对高度监督网格 `s1_187`：BASE x∈[0.8,3.2]m的17列、y∈[-0.5,0.5]m的11行，总M=187；x间距0.15m，y间距0.10m。`ground_presets.s1_187_ground_grid()`返回完整`GroundGridCfg`。标签始终是扫描时沿机体z轴的有符号相对高度`h_B`（通常为负），**不是地图绝对世界高度**。任务注册与任务专用CLI默认采用该网格；`--grid-preset s1_187`仍可以显式选定，或者用完整`--grid-x`及`--grid-y`覆盖；无论如何始终将完整坐标和语义纳入Checkpoint身份。M12是历史工程夹具，不是正式任务默认网格。修改同一M下的点位也会改变grid identity；完整训练恢复须匹配全部坐标与语义。

### 修改地面监督范围（不改变187维输出）

正式任务当前网格由`src/hexapod_mjlab/tasks/confined_locomotion/ground_presets.py`中的**四个可直接编辑的边界值**定义：

```python
S1_187_X_RANGE_M = (0.8, 3.2)  # 最近端、最远端
S1_187_Y_RANGE_M = (-0.5, 0.5) # 右侧、左侧
S1_187_NX = 17
S1_187_NY = 11
```

`ground_grid_from_rectangle(...)`复用已有的`GroundGridCfg.from_ranges()`，按照y外层、x内层生成187个点，经过6位小数规范化后得到最终有序监督坐标；此步骤能避免无意义的浮点尾差使历史Checkpoint网格身份改变。实际标签仍是扫描时沿BASE z轴的有符号相对高度，**不是世界系地图高度**。只修改四个边界数字即可改变当前范围；若仍保留17列×11行，网络ground_head仍是187维，但每个输出索引对应的位置发生变化。目前左右镜像损失需要`y_min=-y_max`：左右不对称的矩形会明确拒绝，而不是悄悄破坏镜像映射。

**优先保留已通过几何验收的`s1_187`基线**。临时对照可在正式训练CLI通过`--grid-x`（完整17个递增值）和`--grid-y`（完整11个递增值）覆盖默认值，不要与`--grid-preset`混用；或者新增一个不同名称的预设，再在任务入口明确选它。不应为了方便直接覆写`s1_187`的坐标，使旧同名配方语义失效。Python调用亦可用`GroundGridCfg.from_ranges((0.9,3.3),(-0.6,0.6),17,11,validity_mode="geometry_only_flat_training")`显式构建测试网格。新范围若仍沿用旧Checkpoint，即使M同为187也必须因`grid_identity_hash`不一致被拒绝；应以新网格重新训练、保存匹配的新Checkpoint再Play，不使用`--allow-source-change`绕过网格不匹配。扩张范围后须重新检查B8近端FPS256、姿态、侧壁与地形遮挡支持，不能凭平地S1-187旧覆盖表外推。

Play点选查询的**近端/远端输入点**（非地面标签点）现在显示成真实三维洋红球体，半径0.12m、直径0.24m，明显大于常规近端点0.06m与远端点0.045m；BASE/WORLD两种视图与被选点位置保持一致，失效、清空或重新选择时旧球体移除。绘制位于`visualization/play.py`的`PICKER_HIGHLIGHT_SPHERE_RADIUS_M`及`_render_pick_highlight`，仅影响显示，不影响扫描输入、训练或Checkpoint。要单独调整球的大小可修改半径常量后重启Play。

## 训练API和入口守卫

类型化factory `confined_locomotion_formal_rl_cfg`要求显式`seed`、`ground_grid`、`num_envs`及`max_iterations`。正式配方绑定用户已确认的PPO/辅助/镜像与ALL_THREE扰动。完整CLI entry为`hexapod_mjlab.tasks.confined_locomotion.rl.entry.launch_formal_training`；该入口先做preflight和checkpoint静态身份检查，再进入官方训练链。正式续跑只接受当前完整checkpoint；`--resume-checkpoint`要求source/model/deps/device/grid/mode等身份一致，恢复后的预算是新增iteration数。

独立工程factory `confined_locomotion_engineering_rl_cfg`要求显式seed和完整grid，最多2环境、恰好1次更新。这个模式只用于有界工程GPU检查，不代表正式预算、训练趋势或学习效果。注册默认**已经包含S1-187坐标**，但`max_iterations=0`和两个训练授权开关仍关闭，因此会在构造网络/Adam前拒绝；仅确定网格不会自动授予训练预算。

CLI在仓库根目录、`hp_mjlab`环境下运行。训练入口在本轮源码中是`train.py`，所有必填项和当前选项应先以已核对的`--help`查看：

```bash
conda run --no-capture-output -n hp_mjlab python \
  scripts/experiments/confined_locomotion/train.py --help
```

入口必须明确提供`--seed`、`--num-envs`、`--max-iterations`。**不传网格参数即使用已确认的S1-187**；可通过`--grid-preset s1_187`显式选择，或者提供完整的`--grid-x`及`--grid-y`覆盖；两种覆盖方式互斥，坐标顺序进入identity。可显式给`--parallel-tol`（默认`1e-6`）、`--resume-checkpoint`、`--log-root`、`--gpu-id`；`--engineering-validation`只能用于最多2环境、恰好1 update的工程见证。187点网格已获得用户首版基准确认，但正式长训预算与地形学习验收未确认，不应据此直接启动大规模长训。2026-10-19以显式`--grid-preset s1_187`通过1环境/1更新真实CUDA验收（历史证据`logs/verification/stageA_S1_187_formal_gpu_20261019_v1/`）。在注册与CLI默认同步后，又**不带网格参数**运行`--seed 20261019 --num-envs 1 --max-iterations 1 --engineering-validation`，真实训练链完成20次优化器step、保存完整Checkpoint、正常关闭；新证据为`logs/verification/current/gpu_verification/task_baseline_integration_20261019/`。上述均为工程验收，不构成学习效果证明。

## Checkpoint与续跑

完整续跑使用`--resume-checkpoint`指定本地完整checkpoint，并由正式preflight比对完整身份。当前要求task、runner/mode、源模块哈希、MJCF/compiled model、grid所有字段、环境数、seed、依赖和device配置相容；缺少、错配或历史schema不迁移。旧源码checkpoint只与对应归档源码一起使用，不能以weights-only自动绕过续跑失败。

Play对checkpoint固定采取weights-only语义，即使文件kind是当前完整训练checkpoint也是如此。它以新play seed和真实T1 reset开始，不加载训练Adam、仿真物理状态、全局随机状态、命令或episode生命周期。weights-only不是断点续跑。故障scene和mean_dev artifact不能作为play checkpoint。

## 任务专用Play

play只接受显式checkpoint和未存在的输出目录；**不传网格参数时直接恢复Checkpoint中保存的完整GroundGridCfg坐标和身份**，不受之后修改训练默认矩形的影响。也可显式指定`--grid-preset s1_187`，或给完整的`--grid-x`、`--grid-y`（不可与preset混用），此时必须与Checkpoint**完全一致**，不能迁移或隐式覆盖旧网格。`--parallel-tol`仅用于显式网格覆盖，无网格参数时由Checkpoint自身恢复。当前真实入口和全部选项可用下列已核对命令查看：

```bash
conda run --no-capture-output -n hp_mjlab python \
  scripts/experiments/confined_locomotion/play.py --help
```

entry使用任务`PlaySession(ground_grid=...)`，先比较当前checkpoint schema/kind/task/M/grid完整identity，再检查CUDA/backend、创建输出目录或环境。可用`--parallel-tol`，默认原值`1e-6`；坐标相同但位置移动不通过identity。需清楚区分手动指令范围：vx在[-1.5,1.5]m/s、vy在[-1,1]m/s、ωz在[-1,1]rad/s；非法输入先拒绝且不改变状态。

Play Viewer中的「候选地面监督范围」默认隐藏，开启后可独立设置最近端、最远端、对称左右半宽，对比蓝色候选矩形和绿色Checkpoint真实边框；可选显示按原网格行列数布置的候选XY点。候选图元在现有标签高度的中位数参考平面上渲染，**只是XY几何投影**，不代表真实地面标签、网络预测或覆盖率；BASE/WORLD切换同步变换，数值修改不触发仿真步进、传感扫描或网络推理，重置按钮只恢复候选框。正式监督位置、地面预测头及原始Checkpoint均不改变。

默认clean、启动暂停、action用网络均值；不抽样、不更新权重。`--start-running`才在创建时直接开始。默认创建绑定`127.0.0.1`的本地Viser viewer；`--no-viewer`关闭viewer，并要求同时指定`--start-running`以无界面运行。可显式使用观察扰动preset`clean/gap/gap_fixed0/range/proprio/all`；每种选择和随机身份写入recipe。指令不会按训练的4秒周期随机换，运行中可手动调节、暂停/继续/单步、执行整episode手动reset或退出。Play不触发训练20秒截断；正式跌倒门保存场景并暂停，须手动reset才继续；任何数值/契约故障保存后永久冻结；碰撞继续运行。

`--allow-source-change`仅放宽weights-only来源哈希规则，不能放宽full resume。play seed是新的play RNG，不会接续训练随机流。play recipe、终止scene和记录均为证据，不是训练checkpoint或可续跑状态。

## 点云编码复用

生产采集和任务Play默认复用未变化扫描的近/远特征，各输出头继续按当前控制观测计算。Python API的`TrainingCollector(..., use_feature_cache=False)`和`PlaySession(..., use_feature_cache=False)`可显式使用原始前向作工程对照；该开关不增加CLI训练配方，也不影响PPO更新路径。缓存身份、失效和恢复约定统一见[接口与约定](../framework/接口与约定.md#点云特征复用)，实测收益及范围见[工程验收](工程验收与复现.md)。
