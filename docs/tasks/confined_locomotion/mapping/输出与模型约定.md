# 形态输出与模型接口

更新：2026-10-12。本文维护当前源码中的形态输出、网络输出形状与初始化约定；启动数值由[平地启动配置](../平地学习与基准测量.md)维护，映射候选的历史实验依据见[设计依据](../reference/设计依据.md#形态输出映射的选择依据)。

## 网络输出

当前 `ConfinedLocomotionNetwork` 接收63维本体向量、3维机身指令、近端点云及远端点云。近端和远端编码器分别输出187维和64维特征；GRU每次前向均从零hidden开始。

网络输出四项：

| 输出 | 形状 | 含义与去向 |
|---|---:|---|
| `envelope` | `(B, 6)` | 米制 `Ê=[前/中/后半宽, 前缘x, 后缘x(负), Δz]`，形态辅助监督使用；不detach。 |
| `action_mean` | `(B, 18)` | 18关节动作均值；生产训练采样分布由策略adapter显式提供。 |
| `value` | `(B, 1)` | critic标量。 |
| `ground_pred` | `(B, M)` | 固定网格各位置的机身坐标带符号地面高度，`M=nx·ny`由`GroundGridCfg`派生。 |

水平形态头以近端特征和本体为输入，输出5个水平原始量；垂向形态头以近端、远端特征和本体为输入，输出一个垂向原始量，不读取指令。地面高度头仅读近端特征。动作均值与价值头读取近端/远端特征、本体、指令及`detach(Ê)`；因此策略/价值损失不能沿包络拼接输入反向更新形态头，但传感器表征到动作/价值的直连梯度仍有效。场景真值、标签与诊断量不进入actor/critic输入。梯度及损失分母见[接口与约定](../framework/接口与约定.md)。

## 六维物理映射

六维正量为 `p=[前半宽, 中半宽, 后半宽, 前缘x, 后缘长度, 根参考高度]`，单位米。当前实现唯一映射为：

```text
p = p₀ ⊙ softplus(raw)
Ê = [p₁, p₂, p₃, p₄, −p₅, p₆ − h_ref]
```

首版启动尺度为 `p₀=[0.59, 0.69, 0.59, 0.89, 0.89, 0.46]m`、`h_ref=0.46m`，`r=1` 且使用PyTorch标准Softplus。首版表示为 `raw`：头直接输出raw，末层权重零初始化、偏置初始化为 `softplus⁻¹(1)≈0.5413248546`，零权重时输出启动基准且头仍可训练。实现还支持显式 `residual` 表示，但当前首版选择raw；构造必须显式给出模式，不设默认。

`p₀`和`h_ref`是注册buffer，不是可训练参数；表示模式进入state保存。缺少模式元数据或跨模式加载会拒绝。原始raw只供诊断接口查看，不进入在线网络输出。对正量非有限/非正、映射结果非有限及重建目标高度非正/非有限均报错；不裁剪、不加机械尺寸floor、不切换激活或求解器。极端负raw的梯度衰减及float32下溢属于数值边界，不能解释成机械安全范围。

形态映射选择基于隔离的数值恢复实验：12组候选中9组合格，用户确认Softplus、`r=1`。该结论不证明网络收敛、机器人可达/安全或联合PPO效果，实验分母和失败原样见[设计依据](../reference/设计依据.md#形态输出映射的选择依据)。
