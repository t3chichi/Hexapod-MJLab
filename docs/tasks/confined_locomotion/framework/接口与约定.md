## 当前代码所有权

纯 PyTorch 计算模块位于 [`src/hexapod_mjlab/rl/confined_locomotion/`](../../../../src/hexapod_mjlab/rl/confined_locomotion/)，不导入任务注册器或构造仿真环境。它拥有观测/标签契约、扫描窗口、网络、映射、PD算式、动作分布、rollout、损失、PPO和镜像映射。任务运行时位于 [`src/hexapod_mjlab/tasks/confined_locomotion/`](../../../../src/hexapod_mjlab/tasks/confined_locomotion/)；负责真实场景、传感器、接触读取、MDP、runtime、采集、checkpoint、CLI和play。

| 职责 | 当前入口 | 约定 |
|---|---|---|
| 数据与身份 | `contracts.py`, `history.py` | `OnlineObservation`与`EnvelopeLabel`/`GroundLabel`分离；`ScanWindow`只在新扫描时写入，读取只返回快照。身份分别按`(env, episode, step)`和`(env, episode, scan)`核对。 |
| 网络与物理映射 | `network.py`, `inference.py`, `mapping.py` | `ConfinedLocomotionNetwork`每次GRU前向均从零hidden开始；输出米制六维包络、动作均值、价值及可选地面预测。映射显式传`envelope_mode="raw"`或`"residual"`。 |
| 策略与更新 | `policy.py`, `distribution.py`, `training_rollout.py`, `losses.py`, `ppo.py` | adapter包装已存在的网络；训练collector提供生产对角Normal；PPO按身份去重后使用唯一Adam。 |
| 真实环境控制 | 任务`runtime.py`, `collector.py`, `transition.py`, `mdp/` | runtime接管真实转移、四个物理子步、扫描与生命周期；collector把策略样本写入纯Torch rollout buffer。 |
| 传感与接触 | 任务`scanner.py`, `ground.py`, `diagnostics.py` | 完整帧采样、真实平地几何标签、raw contact table和body映射均由任务侧提供。 |

`GroundGridCfg`是唯一训练/播放网格类型。声明字段严格为`x_coords`、`y_coords`、`validity_mode`、`parallel_tol`、`body_xyz_semantics`；`nx`、`ny`和`num_points`派生自有序坐标，`grid_order`为既有身份常量。坐标严格递增、有限且可由float32区分。播放API要求`PlaySession(..., ground_grid=...)`；没有隐式最终网格。

真实地面provider从编译模型读取唯一静态水平plane及其世界位置/法向/摩擦/尺寸，并按扫描时完整根位姿将固定机身xy点沿机身z轴求交。标签保存扫描时机身坐标`[x_B,y_B,h_B]`和带符号高度；地面通常在根下方，因此`h_B`通常为负。近乎平行的整行查询标为几何无效并以零隔离。`geometry_only_flat_training`表示所有合法几何位置参与地面监督，不表示该位置受雷达直接观测或无遮挡。

## 观测、点云与动作

在线本体向量按`[lin_vel_b(3), ang_vel_b(3), gravity_b(3), joint_pos_rel_ref(18), joint_vel(18), prev_action(18)]`排列，共63维；机身指令`[vx, vy, ωz]`另列3维。点为扫描采集时机身坐标下的米制xyz三通道，mask独立存放；正常无回波的最大量程端点是有效点，缺失/填充槽必须为零且mask为false。角键由上游明确提供并稳定排序。近端为当前扫描256点，远端为10次不同扫描、每次64点；每次新点序列编码h0=0，不在控制步之间携带GRU状态；无梯度采集/play可复用相同扫描的编码特征。固定观测倍率仅在网络前向施加一次。

`ConfinedPolicyAdapter`提供`forward`、`mean_actions`、`sample`、`evaluate_actions`、`log_prob_actions`及`unique_parameters()`。生产训练必须显式注入`IndependentDiagonalNormalProvider`；无provider时概率/采样API拒绝调用。raw动作与其旧log-prob同时保存，log-prob对应未裁剪动作；执行动作另按±100裁剪。adapter不执行环境step，也没有`forward_batch`便利API。

纯计算PD接口把raw动作裁到±100，乘0.25rad并加固定T1参考，随后用当前关节位置/速度算PD力矩并裁剪到±80N·m。任务runtime在每个50Hz控制步执行一次动作目标，四个200Hz物理子步分别使用最新状态重算PD；单次纯函数调用不会推进仿真。

## 点云特征复用

`ConfinedLocomotionNetwork.forward()`仍接收原始观测和点块，每次重新编码并保留梯度，供PPO和数值对照使用。`encode_points()`返回`PointCloudFeatures(near_feature, far_feature)`；`forward_from_features()`校验特征的批量、设备、float32及有限性，并执行原有各头。网络子模块和参数名保持，特征对象不是模型状态。

`rl/confined_locomotion/inference.py`的`PointCloudFeatureCache`是普通Python运行时对象，由collector或PlaySession持有。`forward(prepared)`只允许`torch.no_grad()`路径，命中时也校验原始在线输入；只复用近/远特征，当前本体、指令和包络计算仍逐控制步执行。缓存不扫描、不排序、不抽随机数、不读标签或live窗口，也不保存跨扫描GRU隐藏状态。

每个环境最多保留一个近端和一个远端条目，分别按传入快照的episode、扫描来源和有序点/mask精确匹配；近端还核对filled状态，远端核对逐点来源scan ID序列。即使ID相同，点值、mask或顺序改变也会重新编码对应行。近远未命中行分别组成编码批，恢复原观测行序；部分reset不使其他环境无条件重新编码。新扫描重新编码完整近端/远端有效序列，不用旧hidden增量追加64点。

完整`collect()`会话开始清空条目并重置统计，结束或失败时释放；会话内动作前与final/bootstrap两处共享缓存。独立`collect_step()`采用单步缓存边界。bootstrap的身份来自旧episode的`final_inputs`，不能替换为reset后runtime的身份。Play从加载后的网络建立缓存，在显式reset/close时清理。

编码器参数对象、正常原位修改版本、设备或dtype变化会使缓存自动失效；runner在更新和加载权重边界另外显式清理。通过`.data`等绕开版本计数的外部改写须由调用方先`clear()`，不作为生产更新方式。`stats`按环境行累计近/远编码数、命中数及调用数，`clear()`保留统计，`reset_stats()`单独清计数。

生产runner与Play在构造网络前关闭TF32，并显式把cuDNN RNN子后端设为IEEE；精度记录同时保存矩阵乘法、cuDNN总项和RNN子项，不能仅由总项推断GRU精度。该设置落实既有CUDA FP32约定；不同编码批量仍按FP32容差验收，不承诺跨设备位级相等。

特征缓存不进入`state_dict`、rollout或checkpoint；完整恢复后从空缓存和已恢复的点云重建。新增源码仍进入checkpoint因果身份，完整续跑的source匹配规则保持严格。PPO、镜像和独立地面监督继续使用新计算图，不复用采集期detach特征，也不改变控制步样本、辅助分母或loss权重。工程证据及性能边界见[工程验收](../training/工程验收与复现.md)。

## 信息与梯度边界

近/远GRU输出维数分别187/64。水平形态头读取近端特征与本体，不读远端或指令；垂向形态头读取近端、远端与本体，不读指令；地面高度线性头只读近端特征，输出维数M由同一`GroundGridCfg`派生。动作均值头与价值头各自独立，读取同一份323维输入：近端187 + 远端64 + 本体63 + 指令3 + `detach(Ê)` 6。动作/价值损失不能经包络预测更新形态头；网络的感知直连梯度仍然有效。两种辅助标签、场景真值与诊断字段不进入actor/critic在线观测。

包络物理量为`Ê=[前/中/后半宽, 前缘x, 后缘x(负), Δz]`，单位米。唯一映射为`p=p₀⊙softplus(raw)`、r=1；后缘还原负号，垂向输出为相对0.46m启动参考的`Δz`。首版采用raw头输出，末层初始化使物理输出等于启动标签且权重仍可训练。极端负值可能使float32正量下溢，数值非法时明确报错；不加机械最小尺寸、输出裁剪或安全solver。形态映射的选择依据和原始变量实验摘要见[设计依据](../reference/设计依据.md#形态输出映射的选择依据)。

## 辅助损失分母与联合更新

首版辅助损失为：

```text
L_total = L_policy + L_value - 0.01 H + 1·L_envelope + 1·L_ground + 0.6·L_mirror
L_envelope = mean_sample(sum_6((Ê - Ê*)²))
l_s = mean_valid_position((H_s - H*_s)²)
L_ground = mean_over_unique_source_scans(l_s)
```

包络六维平方误差先按单样本求和，不除以6，再按batch平均。地面先对单个扫描帧内的几何有效位置平均，再对完整rollout内按环境、episode、scan和grid身份去重后的有效扫描等权平均；无有效位置帧不进分母，空集合跳过并记录覆盖。实际优化分4个桶时，第j桶用`(4/|S|)Σ l_s`，再对四桶平均，恒等于全体`S`帧等权平均；不得除以桶内局部帧数。原/镜像对在来源帧内部先平均，不增加真实扫描数。

PPO每rollout采集24个控制步、5个epoch、每epoch4个minibatch。优势在完整rollout上用`torch.std(correction=1)`统一归一化一次。联合损失一次backward；共享参数按对象身份去重后全部进入一个Adam，联合梯度范数只裁剪一次（上限1）。KL只调整同一Adam学习率，无提前停止。训练FP32，不用AMP、不截断log_std，也不把学习率调度误称KL硬约束。确切数值与奖励公式由[平地启动配置](../平地学习与基准测量.md)维护。

任何身份、形状、非有限、标签/网格不匹配均拒绝或保存现场并停止；无效标签通过mask隔离而不是`nan_to_num`。首轮纯计算106项CPU回归与21项独立输入/梯度检查是2026-10-05时的历史证据，不能替代真实仿真、当前源码GPU门或学习效果。当前状态见[功能状态](../training/功能状态.md)。
