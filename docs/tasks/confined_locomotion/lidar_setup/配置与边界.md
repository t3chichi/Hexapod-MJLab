## 安装坐标与场景射线

原 AIRY 光学生成器以局部`+z`为穹顶轴，而玻璃外壳朝向局部`+y`。模型在传感器空joint及MJCF body应用局部`Rx(−π/2)`对齐；已对齐后的`lidar_sensor` site由`resolve_lidar_mount`读取，扫描器不再叠加90°旋转，也不使用旧fallback。当前近似安装位置约为BASE `[0.644974, 0, −0.164512]`m，光学穹顶轴约`[0.995004, 0, −0.099834]`，即前向下倾约5.73°。这是仿真模型坐标，尚非实机标定。

光学轴映射为：局部`+x`约朝BASE左侧`+y`；局部`+y`朝上且略向前；局部`+z`为穹顶轴，朝前且略向下。仿真方位角围绕光学坐标定义，不可把某个角度直接当作机身竖直轴的方位角。机械/光学装配变动需要重做真实模型site及坐标验收。

每次真实扫描使用完整900方位×96通道，共86,400条射线、15m最大量程，完整帧先按校正后的安装轴和当前可配置锥分组，并对近端施加BASE-x端点上限，再对两组采样。当前正式B8配置为 θ=28°、δ=56°、`split_max_forward_x_m=3.5`；截断不是距雷达欧氏距离，角度参数含义为实际半开角62°。生产`pool_azimuth_stride=1`，没有方位预抽稀。

场景校验要求编译模型恰有一个水平`mjGEOM_PLANE`，摩擦为滑动1.0、扭转0.005、滚动0.0001。射线用该真实plane构建Warp mesh代理；代理默认半宽100m，仅供射线相交，不代表物理地面有限边界。每次raycast前检查代理mesh覆盖传感器周围15m最大量程球的投影，避免mesh边缘制造假无回波。扫描器不将机器人几何放入raycast场景：首版环境扫描不含自遮挡、自回波或机器人点过滤；物理碰撞仍包含机器人完整资产。

## 分组、采样及来源身份

近端从完整近角组中做256点FPS；FPS选择每次唯一源射线，平局不会重复选择，候选不足时按真实数量选择并以`valid=False`零槽补齐。远端从完整远角组依传感器角键稳定排序，再按`floor(j·M/K)`均匀抽64点；远端每个窗口槽来自不同的新扫描，最多保留10次，绝不复制旧扫描来填满。候选不足同样只保留实际点并将剩余槽置零、mask为false。

ray miss的身份为内核精确写出的`dist == far_plane`，不设近距离阈值或误差带。miss端点按原始射线方向重建在15m处，作为有效三维点；真实命中、原始距离、无回波标记、射线方向和采样源ID保留供独立核查。NaN/Inf、负距离或超量程距离是故障，记录原始证据后抛错，不以裁剪、mask或无回波端点清洗。只有消费副本参与扰动和采样；原始backend像素/距离不原位改写。

点云坐标为扫描采集时机身坐标、单位米、xyz三通道；标签和角键与原始scan ID绑定，网络不会接收第四个mask通道。相同扫描在相邻控制步复用，不重复写入窗口，不再次发射或重抽扰动。runtime负责每环境10Hz扫描时钟和episode内scan身份；控制50Hz、物理200Hz，每控制步4个物理子步。10槽远端历史代表10次不同扫描；reset后立即采集唯一首帧，网络不等待窗口凑满，帧按采集时机身坐标保存，不做运动补偿。

## 地面辅助标签

地面网格是固定、递增的机身xy采样坐标，沿扫描时完整机身z轴查询当前编译模型中的真实plane。查询高度`h_B`相对根参考点，正负均合法；标签是扫描时机身坐标`[x_B,y_B,h_B]`，与世界竖直`z_ground−z_root`、光学射线端点及六维包络`Δz`都不是同一量。plane单位法向与机身z轴方向的点积绝对值小于配置`parallel_tol`时，整行网格几何无效并置零，避免输出非有限交点。

唯一配置声明字段为`x_coords`、`y_coords`、`validity_mode`、`parallel_tol`、`body_xyz_semantics`；点顺序固定为y外层递增、x内层递增，索引`iy*nx+ix`。M由同一坐标对数派生。首版`geometry_only_flat_training`对所有几何有效位置监督，不按FPS点、命中支持、遮挡或每帧回波动态裁网格；观测支持只做独立诊断。M12只作为工程夹具，M、范围和分辨率仍需跑通后根据真实覆盖精调。换位置或M都会改变完整grid身份；不允许只匹配M继续加载旧完整训练状态。
