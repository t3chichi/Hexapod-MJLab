雷达测距噪声起步规则（2026-10-07用户确认；2026-10-09 P6工程验收）：首版训练对每次新扫描中未被缺口排除的实际命中射线，在传感器坐标中加入独立加性距离噪声ε∼N(0,0.015²)m，保持原射线方向；这是以[官方96线手册](https://robosense-robotics.github.io/product-manual/en/Airy/#24-specifications1)有条件的1.5cm（1σ）典型精度作尺度参考的简化模型，不声称硬件噪声服从独立同分布高斯、所有通道/距离精度相同或已实测。仅对消费副本计算d_obs=clip(d_raw+ε,0,15)m，原始测量、真实命中/无命中状态及契约故障证据保持；正常无回波仍固定15m，缺失/填充不加噪、不转为有效点，噪声上界饱和不倒推改变原始命中身份。此处距离边界是噪声模型的消费规则，不用于修复原始非有限/越界故障，也不定义实机盲区。

在完整原始帧的消费副本上加入该噪声，再按既定外参变换、分组及FPS/均匀采样；一帧仅生成一次，控制步复用、历史窗口、PPO采样存储/重放及更新均复用当时的带噪输入，不再次抽噪。真实地面标签、包络标签、物理奖励及其时刻不随噪声改变。保留无噪声基础GPU检查及对照；缺口和测距噪声先各自验收再检查组合，不改变镜像分步顺序或自动增加丢点/异常点/偏置/角噪声。当前通用LidarSensor.apply_noise使用距离比例噪声、覆盖无命中并原位写回buffer，不能直接打开其开关冒充本规则；P6已在新任务消费副本链路独立接入并完成真实GPU验收，旧任务默认及原始证据不变。

本体观测噪声起步规则（2026-10-07用户确认；2026-10-09 P6工程验收）：沿用参考项目的零均值有界均匀加性噪声方式，首版总强度noise_level=1.0；参考spider_nomal配置为1.5，本规则主动减轻起步扰动，不自动继承完整参考配方或特权critic。以下为观测倍率施加前、机身坐标/物理单位上的独立分量扰动半幅，不是高斯标准差；正式实现按字段构建63维观测，不能直接使用旧66维切片。

| 本体噪声字段 | 每分量扰动范围（未乘观测倍率） |
|---|---|
| 根线速度 | U(−0.1,+0.1)m/s |
| 根角速度 | U(−0.2,+0.2)rad/s |
| 关节参考偏差q−q_ref | U(−0.05,+0.05)rad，固定q_ref不变 |
| 关节速度 | U(−1.5,+1.5)rad/s |
| 重力方向 | 每分量先加U(−0.05,+0.05)，再将向量归一化；幅值为归一化前值，归一化后分量不再独立均匀 |
| 指令、上一步裁剪后动作 | 不加噪声 |

总强度1.0与各基础半幅相乘一次，再由网络按已确认倍率缩放一次。参考数值来自el4090_legged_gym的spider_nomal/el4090_spider_config.py noise及ElSpider._get_noise_scale_vec/compute_observations；均匀加性方式也见[legged_gym原实现](https://github.com/leggedrobotics/legged_gym/blob/master/legged_gym/envs/base/legged_robot.py)。本规则仅用作训练扰动，不声称为实际编码器/IMU/速度估计器的标定精度或完整误差模型。

每个环境每次新控制观测（50Hz）生成一次本体噪声，采样及PPO保存/更新使用当时的同一份带噪观测；actor/critic及读取本体的形态头共用同一份，指令信息边界保持，地面头仍只读近端点云。读取、网络重复前向或reset未选中的环境不额外抽噪；选中reset生成新的观测身份，不复用旧episode观测。真实物理状态、点云/标签坐标变换用的根姿态、接触、PD反馈、奖励/终止及真实辅助标签均不受此观测噪声修改。该规则不加入观测偏置、漂移、延迟、丢失或PD反馈误差，保留无噪声基础GPU验收与单独/组合对照；P6已复核观测身份、倍率、单位重力、共享输入、reset及更新重放，并完成代码及真实GPU工程验收。

### 已确认的速度跟踪奖励（2026-10-07）

令c_t=[vx*,vy*,ωz*]为执行该控制步动作时的机身速度指令，v_B和ω_B为真实实际机身速度，所有量均使用未施加观测倍率的物理单位：

- 平移得分r_v=exp(−[(v_Bx−vx*)²+(v_By−vy*)²]/s_v)，s_v=0.25(m/s)²；权重5。
- 转动得分r_ω=exp(−(ω_Bz−ωz*)²/s_ω)，s_ω=0.25(rad/s)²；权重2.5。
- 每个控制步按Δt=0.02s累计，r_tracking=Δt·(5r_v+2.5r_ω)。分母是平方误差尺度，不是标准差0.25，也不在执行时再次平方。

公式与权重来自六足参考项目base/legged_robot_rew_mixin.py和spider_nomal/el4090_spider_config.py；s_v/s_ω沿用继承的base/legged_robot_config.py tracking_sigma数值，分开标注物理量避免混淆。平移合误差0.5m/s或转动误差0.5rad/s时，对应得分exp(−1)≈0.368。奖励必须与该步实际执行指令匹配，周期重采样后的下一条指令不能回用于上一动作的跟踪奖励。

h_actual保持[架构](../../research/训练架构对齐.md#3-参考预测与实际形态)规定的根参考点相对真实地面的竖直高度，不是世界坐标绝对z，也不是沿机身z轴的射线距离。可将从根参考点指向真实地面的相对向量和重力方向转换到完整机身坐标后作投影计算：d_B=R_WBᵀ(p_ground−p_root)，u_B=R_WBᵀu_W（u_W为单位竖直向上向量），h_actual=−d_B·u_B。当前真实水平plane的参考地面点必须来自已核验的场景几何；高度奖励使用控制步实际状态，不用10Hz扫描时标签或地面预测头替代实际高度测量。机身z轴地面辅助标签的既定查询及采集时刻保持不变。

用户明确：后续任务直接跟踪形态预测的高度h_target=h₀+detach(预测Δz)，不额外加入与形态预测和观测无关的随机、阶跃或独立高度目标序列。启用后，以预测目标跟踪替换本轮固定0.46m高度项，不同时追逐两套高度目标；后续权重与完整形态引导仍在对应阶段确认，目标取动作采样时预测，保存实际奖励，更新不重算历史目标。首次平地稳定行走后的h₀是固定高度目标配方下的实测行走基准，设定值0.46m不能直接冒充实测值；不把平地验证报告解释为已验证复杂环境的变高跟随能力。

训练观察分别记录机器人速度跟踪、实际高度与固定目标误差、跌倒/碰撞，以及六维预测包络、对应参考标签、逐维误差和包络辅助损失。两类记录按环境/episode/控制步身份关联，不能将预测与标签一致解释为实际机器人已跟踪完整目标形态。当前平地包络标签固定且初始化输出等于标签，零损失不证明已学会环境相关形态预测；该阶段用于观察联合更新稳定性，环境相关预测能力须在后续变化场景验证。记录要求随训练模块接入，本次确认不表示已产生训练结果。

## 3. 地面辅助与启动损失

启动配置包含PPO、包络辅助和近端地面高度辅助。用户于2026-10-07确认平方误差：包络在单个样本的六个米制输出维度上累加求和，不除以6；地面在有效监督位置上取平均；两项起步权重λ_E=λ_H=1，P3/P4实际GPU短优化已核对loss、梯度和更新，学习效果尚未验证。包络标签对应当前控制步的动作前状态；地面标签对应扫描时状态。两者关联和形态奖励保存规则见架构文档。

包络批损失采用L_E=(1/N)Σ_nΣ_{d=1}^6(Ê_nd−E*_nd)²，N为有效包络样本数；“累加求和”指六维误差相加，批内样本仍取平均，避免仅因批大小改变辅助强度。不对物理量作额外尺度归一化；后缘和Δz均使用对外米制输出，辅助路径不detach。相同样本/误差下，该形式是此前六维取平均建议的6倍，权重1的实际影响须检查共享编码器梯度。

地面平方误差仅统计有效标签，填充或无效位置不作为零高度监督、不计入分母；无有效标签时跳过该批地面辅助并记录有效率。首版平地采用下文已确认的固定网格几何有效掩码；独立扫描计数与两级平均也已确认。P2/P3已实现并验收来源聚合与两类loss及真实联合更新，正式总守卫保持。

用户于2026-10-07确认地面辅助按独立扫描等权：每个用于一次PPO更新的完整采集批（rollout）内，按(env_id, episode_id, scan_id, grid_identity_hash)去重，每帧只占一份地面监督样本。去重范围不是单个minibatch或落盘分段；原始控制步记录继续完整保存。相同身份的扫描输入/标签必须一致，若不一致应视为契约故障，不任意挑选或平均冲突记录。

对独立扫描s，令有效位置集合为V_s，则l_s=Σ_{j∈V_s}(预测h_sj−真实h_sj)²/|V_s|；对至少有一个有效位置的独立扫描集合S，L_H=Σ_{s∈S}l_s/|S|。各帧等权，帧内有效位置等权，不因重复控制步数或该帧有效点数量改变帧权重；λ_H仍为1。无有效位置的真实扫描仍保留身份和诊断记录，不参与损失分母；S为空时跳过该批地面辅助并记录覆盖率。不能仅在新扫描控制步添加辅助后再用全部控制步数作分母，这会稀释已确认的辅助强度。

策略、价值和包络辅助继续使用全部控制步数据，不随地面去重。去重后的地面样本允许参与正常多轮优化，每轮以当前网络重新前向及反向，扫描时真实标签保持不变；每个优化epoch按独立扫描等权组织地面样本。去重只限定于当前完整rollout，不设置全局“训练过即永久跳过”；跨rollout边界仍被使用的扫描可在下一批再次参与监督。更新/minibatch布局属于工程实现，但须验收最终计数、分母及权重符合本节。

**2026-10-10用户确认的首版定义：纯左右交换，作为近似对称增强。** 关节置换A按名称配对RF↔LF、RM↔LM、RB↔LB，各腿HAA/HFE/KFE同类关节同号交换；从实际模型加载的关节顺序构造索引，不照搬旧任务切片。动作映射为`M_a(a)=A a`，动作均值、raw动作、上一步执行动作、相对关节观测`q−q_ref`及关节速度均按A交换，首版不加固定偏移b。线速度、重力和米制点云等极向量按`Q=diag(1,−1,1)`反射，角速度等轴向量按`det(Q)Q`反射；指令为`(vx,−vy,−ω_z)`。本体63与指令3仍分列，网络连接与梯度边界不变。
