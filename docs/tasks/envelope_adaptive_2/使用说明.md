# EA2 使用说明

更新：2026-10-03。当前默认teacher为`whole_polygon_preview_axial_v1`（`exact`），主安全间隙0.10米。本任务是脚本载体上的190维观测→5维包络监督学习，不是机器人关节闭环，也不通过PPO训练。

## 环境与已验收模型展示

以下命令在仓库根目录、`hp_mjlab`环境中执行。`PYTHONPATH=src`保证使用当前checkout；数据、模型、实验与验收输出分别在`logs/ea2/{data,runs,oracle_refinement,acceptance}/`。展示和复现所需产物不随Git提交自动下载，具体目录见[选型与验收](oracle/选型与验收.md)。

```bash
conda activate hp_mjlab
PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.play \
  logs/ea2/runs/exact-release-20261003-baseline/model.pt \
  --oracle exact --seed 1 --num-envs 1
```

可增加`--full-lidar`显示完整点云，或`--mode window`切换固定窗口推理。颜色含义：黄色为几何有效oracle，橙色为紧急参考，灰色为不可用/未认证参考，青色为学生预测；红点是187选定通道，绿点是其余完整扫描命中点。有限显示预算只减少绘制点数，不改变采样或监督输入。

不传`--oracle`时play/eval按checkpoint恢复教师，缺少teacher元数据的旧模型恢复legacy。显式覆盖教师只用于对照，不代表旧模型已接受新标签训练。新学生模型的短训练验证R²仍为负，展示oracle不能用来证明网络预测可靠。

## 新采集与训练

以下目录是新实验示例；已有冻结证据目录应继续保留。新采集默认exact；重现旧迁移teacher时改为`--oracle legacy`。训练会识别数据来源，禁止静默混合不同teacher标签。

```bash
PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.collect \
  --oracle exact --seeds 1,7 --num-envs 8 --num-steps 800 \
  --out-dir logs/ea2/data/example

PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.train \
  --data-dir logs/ea2/data/example --seeds 1,7 --epochs 5 \
  --out-dir logs/ea2/runs/example

PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.train \
  --data-dir logs/ea2/data/example --seeds 1,7 --epochs 5 \
  --aux-ks 25,50,100,200,300 --aux-mode recall --aux-beta 0.5 --safe-lambda 1 \
  --out-dir logs/ea2/runs/example-aux

PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.eval \
  logs/ea2/runs/example/model.pt --seeds 1,7 --num-envs 8 --num-steps 700 \
  --data-dir logs/ea2/data/example
```

## 管线与检查

```bash
# 新运行会重新采集、训练和评估；--play以十步交互显示结束
PYTHONPATH=src python -m hexapod_mjlab.tasks.envelope_adaptive_2.sl.scripts.pipeline \
  --small --play --run-name my-ea2-check

PYTHONPATH=src python tests/ea2/teacher_supervision_gate.py
PYTHONPATH=src python tests/ea2/teacher_environment_gate.py
```

`pipeline --small`使用迁移阶段小预算（两图各800×8帧，两配方各5轮），但当前采集使用新teacher；不加`--small`会使用SLConfig的大规模默认预算。它不同于已冻结的新teacher发布预算（两图各800×4帧、stride30、batch8），两者结果不能混称。

历史对齐与预算见[迁移验收](迁移验收.md)，当前安全/有效性契约和四图验证见[选型与验收](oracle/选型与验收.md)，原始静态对照和负结果见[实验记录](oracle/实验记录.md)。公共绘制在`src/hexapod_mjlab/utils/visualization/`，只接收世界坐标数据，可以被其他任务复用。
