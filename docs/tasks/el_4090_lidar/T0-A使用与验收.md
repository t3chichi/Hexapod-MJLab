- 平面在物理上无限；感知和高度视图的有效域为`[-13,13]²`，域外射线按未命中处理。T0根位置限定`[-11,11]²`，为真实占据与局部高度采样留空间，越域会终止且评测失败；不能在视图外宣称监督有效。机器人自遮挡仍未实现。
- 诊断只观察原生求解接触与状态，不增加forward/step。200Hz接触对应求解器积分前状态，qpos/qvel对应积分后状态；原生边界forward另检查积分后几何。物理警告包括实际GPU overflow位、全状态有限性和数值角度越界；覆盖范围与计数显式记录。
- 保持/评测禁用auto-reset。首个终止状态与事件先冻结，再只复位已结束环境以继续采集其余环境；不会把多次尝试拼为成功。控制前强制command后重新计算观测；每指令固定32条，批大小不改变分母。
- 镜像按固定默认offset换算绝对关节目标、相对位置及历史动作；点云角键的同角度历史点采用确定性坐标排序，真实镜像两次恢复序列。适配和排序都位于T0内，不改变共享PPO或旧任务。

静态保持沿用T1的5秒、32环境、200Hz、逐关节时间RMSE、全过程漂移/高度/姿态、末0.5秒速度、真实支撑和名义64N·m余量阈值。GPU根部静止受力用原生`qfrc_bias−qfrc_passive−qfrc_actuator−qfrc_constraint`残差核验，尾段力/力矩仍≤2N/1N·m；同源CPU模型独立核验实际接触点、正确body质量映射的COM与刚性静力LP。经典MuJoCo逆动力学在GPU末态上的软接触力会有后端差异，诊断原值保留，不把它当作GPU实际承载力，也不声称两后端力值已完全一致。这里是不同后端的明确验证分工，不修改T1既有测量脚本或验收结论。

评测按测区最大高度误差、最大绝对侧移、站立最大偏移验收；按实际逐帧指令计算vx MAE，全episode保留安全事件。早终止、空测区、字段/长度错误、NaN、计数矛盾或记录缺失均失败，不因均值抵消或返回原点通过。原阈值：倾角≤15°、体高误差≤0.05m、前进位移≥3m、vx MAE≤0.10m/s、侧移≤0.30m、站立偏移≤0.05m、施加力矩≤80N·m。29/32每指令的学习行走门属于T0-B，不要求5迭代短训练达到。

## 操作

```bash
conda activate hp_mjlab
# 完整固定预算验收；准备失败则后续BLOCKED，整体非0退出
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 python scripts/tools/t0/run_acceptance.py
# 仅准备门；会保留完整反例，但不能自称整阶段通过
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 python scripts/tools/t0/run_acceptance.py --prepare-only
# 无GPU单元检查
PYTHONDONTWRITEBYTECODE=1 python tests/t0/test_units.py
# 对指定正式run做身份核验、raw重算与checkpoint前向；写新目录
PYTHONDONTWRITEBYTECODE=1 python scripts/tools/t0/replay_verify.py --run-dir <run绝对路径>
```

短训练固定seed=1、32×24×5=3,840步、含编译20分钟上限。仅实际OOM证据允许16环境，需提供失败JSON：`--num-envs 16 --oom-evidence <失败报告>`；评测仍64条。独占run下产物不覆盖，源码/完整模型mesh/扫描输入/冻结T1库和依赖身份先冻结、末尾再核对；配置、模型、checkpoint、episode及安全数组另行封存SHA。缺文件、换源码/模型或输入数据后，重放先拒绝，不执行被替换的科学计算。

T1库的必要冻结副本随Git保存在`docs/research/morphology/evidence/library.json`，与原验收库逐字节一致；完整T1/T0运行轨迹、编译模型及训练权重留在`logs/`，不混入源码提交。复现结果仍需要CUDA和对应依赖，源码/输入身份相同不要求GPU浮点轨迹逐字节相同。
