## 获取明确版本

使用基线tag，而非假定远端默认分支包含开发机所有改动：

```bash
git clone --branch confined-flat-2-pretrain-v1 --single-branch \
  https://github.com/t3chichi/Hexapod-MJLab.git
cd Hexapod-MJLab
git rev-parse HEAD
git status --short
```

tag检出默认是detached HEAD；需要开发时另建分支。身份比较以commit及文件内容为准，不以文件夹名称或文档日期代替。

## 安装与预检

目标机先确认NVIDIA驱动可见、操作系统及可用显存，再运行：

```bash
conda env create -f environment.yml
conda activate hp_mjlab
python -m pip install -e .
python -c 'import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else "CUDA unavailable")'
python -B tests/confined_locomotion_2/run_checks.py
```

`environment.yml`锁定主要发行版本，CUDA wheel变体与目标驱动需另外核对；基线开发机实际版本见[evidence中的environment.json](../baseline/evidence/environment.json)。此说明不宣称目标5090已兼容，也不要求修改系统CUDA toolkit来匹配一个未验证的猜测。

CPU通过后，运行有限真实GPU检查（2环境，保留正式扰动与镜像）：

```bash
python -B tests/confined_locomotion_2/check_gpu.py \
  --output "logs/verification/confined_locomotion_2/deploy_$(date +%Y%m%d_%H%M%S)" \
  --gpu 0 --num-envs 2 --far-sampling hit_only_10m --raycast-mode sparse \
  --sparse-selection src/hexapod_mjlab/tasks/confined_locomotion_2/assets/fixed_channels/v1_hit10/near_x6_far_x10.npz \
  --save-interval 1
```

这里间隔1专用于有限检查：验证第1轮真实周期保存、恢复后第2轮累计保存及TensorBoard。正常训练默认50；该检查模型不是长训起点。检查要求恢复边界和同一保留rollout优化器重放一致，不承诺未来物理轨迹逐位重演。

Play或采集切换检查需要显式提供匹配配置的checkpoint；基线不附训练模型。基础训练入口可从零生成模型，示例见[快速开始](../../../../src/hexapod_mjlab/tasks/confined_locomotion_2/快速开始.md)。不得把legacy `all_endpoints` 模型当成hit10模型使用。

## 后续容量与学习验收

目标机GPU工程检查通过后，固定near×6/far×10、hit10、24步rollout及正式镜像/扰动，分级增加环境数，测采集、更新、保存耗时、PyTorch显存与整卡显存。保留运行余量后选择环境数，再确定有限单种子学习预算。未做这些测量前，不指定5090的最终环境数或训练耗时。

本次源码资源定位变化会改变完整checkpoint的源码身份；旧模型可在匹配sampling下用于Play，不能通过改写身份绕过严格恢复。
