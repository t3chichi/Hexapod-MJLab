## 文档维护规则

- 任务说明放`tasks/<任务名>/`，oracle等子主题放相应子目录；跨任务研究方案放`research/`。共用开发规范需要时放`development/`，不预建空文件夹。
- `docs/`根目录仅保留导航与维护规则。图表、冻结证据放所属主题的`figures/`、`evidence/`目录。
- 同一主题保留一份当前方案或使用说明；旧规划完成后把独有结论并入验收或实验记录，删除重复过程文件。失败实验和可复现证据继续保留。
- 文档注明日期及已验收/历史/待定状态，区分teacher几何、学生预测与机器人闭环的结论，避免将建议写成已经实现。
- 移动文档时同步更新仓库README、测试说明、相互链接和图表生成脚本。冻结证据内容不因整理而重写，路径迁移不改源码与实验身份。
